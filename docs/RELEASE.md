# ASMR 自动翻译工具 v1.23.0

把日语 ASMR 音声 / 视频批量翻译成中文字幕（`.chs.srt`），字幕直接生成在源文件旁边，播放器可以自动加载。

**全程离线**，不上传任何文件。界面是 Rust + WinUI 3，AI 推理跑在本地的 Python 环境里。

---

## 下载

**程序分两个包，两个都要下、都要装。** 这是为了让你升级时只重下 17 MB，而不是 6 GB。

| 包 | 内容 | 大小 | 下载位置 |
|---|---|---|---|
| **1_主程序_安装包.exe** | 程序本体 + 界面 + llama.cpp | 17 MB | 👉 本页下方 Assets |
| **运行环境.zip** | Python 环境 + 全部模型权重 | 6.2 GB | 👉 百度网盘 |

**运行环境包（百度网盘）**：
链接 <https://pan.baidu.com/s/1O8gv32IN4WmfHrgHraQbGw?pwd=c98a>　提取码 `c98a`

## 安装

1. 双击 `1_主程序_安装包.exe` → 一路下一步（**不需要管理员权限**）
2. 解压 `运行环境.zip`，双击里面的 `2_运行环境_安装包.exe` → 一路下一步（同样不需要管理员权限）

先装哪个都行。两个包装到同一个目录 `%LOCALAPPDATA%\ASMR自动翻译工具`，共用同一个卸载入口。

装完桌面会有快捷方式「ASMR 自动翻译工具」。

### 安装前请确认

- **磁盘空间 ≥ 7 GB**（程序 17 MB + 环境 5.6 GB + 模型 5.3 GB，安装过程还要临时占用）
- **Windows 10 1809 或更高**（WinUI 3 的硬性要求，Win11 当然可以）
- Windows Defender 或其它杀软如果拦截，选择「允许」—— 安装包未做数字签名，可能触发 SmartScreen 提示（点「更多信息」→「仍要运行」）

## 用起来

1. 拖视频/音频文件进窗口，或者点「添加文件」「添加文件夹」
2. 选处理模式（见下表）
3. 点「开始处理」
4. 等它跑完，字幕出现在源文件旁边，文件名是 `原文件名.chs.srt`

| 模式 | 显存要求 | 用的是 | 速度 |
|---|---|---|---|
| 全量模式 | ≥ 8 GB | whisper large-v2（CUDA） | 最快 |
| 精简模式 | ≥ 6 GB | 同上，模型量化版 | 快 |
| 兼容模式 | < 6 GB / 非 N 卡 / 核显 | SenseVoice + Qwen（Vulkan 或 CPU） | 慢一些 |

程序会自动检测你的显卡，并**禁用跑不动的模式**。副标题会显示当前用哪个后端在加速。

## 常见问题

**Q：网盘里的运行环境是 5 个文件，怎么装？**
解压 `运行环境.zip`，5 个文件会一起出来。保持它们在同一个文件夹，双击 `2_运行环境_安装包.exe` 即可，它会自动找旁边的 `.bin` 分卷。

**Q：装完打开报错 / 一直「检测中…」**
先确认两个包都装了。只装主程序包的话，程序找不到 `env\python.exe` 和模型，会一直卡在设备检测。

**Q：提示「未检测到 NVIDIA 显卡」，只能选兼容模式**
正常。要么你的卡不是 NVIDIA，要么驱动太旧。装最新驱动，或者就用兼容模式（同一套流程，只是慢）。

**Q：杀毒软件报毒**
安装包没有数字签名，是自解压式的 Inno Setup 安装包，容易被误报。程序本身不联网、不写注册表以外的地方，源码全部公开在这个仓库里。

**Q：字幕在播放器里不显示**
字幕文件是 `xxx.chs.srt`，播放器需要手动选「加载字幕」，或者把播放器设为自动加载同名字幕（PotPlayer、mpv、VLC 都能设）。

**Q：想换机器 / 重装**
直接重装两个包即可，程序没有联网激活、没有机器绑定。

**卸载**：设置 → 应用 → 「ASMR 自动翻译工具」→ 卸载（两个包共用一个卸载项）。
