# 术语后处理表（三个模式通用 / v1.30.6）
#
# 作用：把译文里「跑偏的写法」改回标准写法。只做纯文本替换，不动别的字。
#
# ── 三种写法 ──
#
# 1) 译后替换（最常用）
#       错误写法=标准写法
#     作用在**中文译文**上。
#
# 2) 译前替换 —— 行首加 `pre:`（v1.30.6 新增）
#       pre:日文写法A=日文写法B
#     作用在**日文原文**上，翻译之前就改。
#     用途：口齿不清统一（ぺろぺろ / れろれろ 归一）、同一个意思的多种
#     日文写法先归一，省得在术语表里写一堆同义条目。
#     注意：字幕里保留的仍是日文原文，只是送给模型的是替换后的。
#
# 3) 条件替换 —— 右侧加 `|条件词`（v1.30.6 新增）
#       错误写法=标准写法|含有的词
#       错误写法=标准写法|!不该有的词
#     只有**译文里出现「含有的词」**时才替换；加叹号反过来（不含才替换）。
#     替换时会保护条件词本身不被切开。
#     用途：治「一写就全局误伤」—— 例如 `乳=奶|乳头` 只在句子里已有
#     「乳头」时替换「乳」，并且不会把「乳头」改成「奶头」。
#
# ── 通用规则 ──
#   · 井号开头是注释；空行忽略；文件用 UTF-8（记事本能存）
#   · 词表越长越先替换，所以不用考虑顺序
#   · 只放「同一个词的不同写法」，别放宽泛的常用词（会把正常句子改坏）
#
# 三个模式都会读它：兼容模式在翻译阶段替换；全量/精简在字幕整理阶段替换
# （全量/精简不经过翻译层，所以只生效 1) 译后替换）。
#
# 两个文件：
#   fixes.txt          对所有作品生效（放通用错译：名字、拟声词）
#   fixes_<音频名>.txt 只对某个作品生效（<音频名>=0pre 里的文件名去掉扩展名）
#
# 例子（把行首的 # 去掉即可启用）：
# 渚沙=凪咲
# 长濑沙=凪咲
# 好可爱=咕啾
# 好舒服=哈啊
# pre:ぺろぺろ=れろれろ
# 乳=奶|乳头
