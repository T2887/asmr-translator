# 术语后处理表（三个模式通用 / v1.30.4）
#
# 作用：把译文里「跑偏的写法」改回标准写法。只做纯文本替换，不动别的字。
# 格式：一行一条  错误写法=标准写法
#   · 井号开头是注释；空行忽略；文件要用 UTF-8（记事本能存）
#   · 词表越长越先替换，所以不用考虑顺序
#   · 只放「同一个词的不同写法」，别放宽泛的常用词（会把正常句子改坏）
#
# 三个模式都会读它：兼容模式在翻译阶段替换；全量/精简在字幕整理阶段替换。
#
# 两个文件：
#   fixes.txt          对所有作品生效（放通用错译：名字、拟声词）
#   fixes_<音频名>.txt 只对某个作品生效（<音频名>=0pre 里的文件名去掉扩展名）
#
# 例子（把行首的 # 去掉即可启用）：
# 渚沙=凪咲
# 长濑沙=凪咲
# 好可爱=咕啾
# 好舒服=哈啊
