# 按作品补充热词（可选文件）
#
# 第4步识别时会读这两个文件，把词并入全局热词：
#   hotwords.txt              对所有作品生效（放通用词）
#   hotwords_<音频名>.txt     只对某个音频生效
#                             （<音频名> = 0pre 里的文件名去掉扩展名，
#                              例如 official01.wav → hotwords_official01.txt）
#
# 格式：每行一个词，也可以用逗号分隔；# 开头是注释。
# 建议只放【人名、地名、作品专有词】—— 通用词已经内置在 d 脚本里。
#
# 实测（R4222 第1轨）：
#   放 凪咲,三野轮凪咲,神社,巫女,迷途者,污秽 之后
#   · 错译「渚沙」6 次 → 0 次
#   · 「神社」0 次 → 2 次
#   · 字幕条数 63 → 52（更贴近官方的 56 条）
#
# 示例（取消注释并替换成当前作品的人名）：
# 凪咲,三野轮凪咲
