# 按作品补充热词（可选文件）
#
# ★ v1.30.4 起，这两个文件有两个读者：
#   1) 第 2 步识别（Haas-ja）—— 作为 ASR 热词，让罕见人名/作品专有词更容易被听对。
#      代价：解码从 greedy 换成 beam search，120 秒音频约 +2~3 秒（+12~19%）。
#      不想要可以在启动前设 ASMR_ASR_HOTWORDS=off。
#   2) 第 3 步翻译 —— 作为「必须原样保留的专有名词」提示词。
#
# 文件名规则：
#   hotwords.txt              对所有作品生效（放通用词）
#   hotwords_<音频名>.txt     只对某个音频生效
#                             （<音频名> = 0pre 里的文件名去掉扩展名，
#                              例如 official01.wav → hotwords_official01.txt）
#
# 格式：每行一个词，也可以用逗号分隔；# 开头是注释。
# 建议只放【人名、地名、作品专有词】—— 通用词已经内置在 d 脚本里。
#
# 实测（R4222 第1轨，翻译侧）：
#   放 凪咲,三野轮凪咲,神社,巫女,迷途者,污秽 之后
#   · 错译「渚沙」6 次 → 0 次
#   · 「神社」0 次 → 2 次
#   · 字幕条数 63 → 52（更贴近官方的 56 条）
#
# 示例（取消注释并替换成当前作品的人名）：
# 凪咲,三野轮凪咲
