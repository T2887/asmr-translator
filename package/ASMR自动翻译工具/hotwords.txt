# ★ v1.40.1 新增：hotwords.d/ 目录（同一系列多个文件共用一组术语）
#
#   模式匹配：文件名就是模式，只要它出现在音频文件名里就加载。
#
#       hotwords.d/RJ277717.txt
#       → 对 RJ277717_01.wav、RJ277717-序章.wav 都生效，不适用于别的作品。
#
#   形式与本文件完全一致（同样支持三列新格式、逗号旧格式、# 注释）。
#   叠加顺序：本文件 → hotwords_<音频名>.txt → hotwords.d/匹配到的组。
#
# 按作品补充术语表 / 热词（可选文件）
#
# ★ v1.30.6 起支持两种写法，**推荐用新的三列格式**：
#
#   新格式（TAB 分隔，一行一个词）：
#       日文<TAB>中文<TAB>解释(可省)
#       凪咲	凪咲	name, girl, 女主角
#       先生	老师	teacher, 男性
#
#     好处：① 模型知道该译成什么（不只是「原样保留」）；
#           ② 解释里写角色设定，人称代词才会选对（她/他、老师/先生）；
#           ③ **只有当前这句日文里出现该词才注入**，不干扰其它句子。
#     实测：`凪咲、どこに行ったの？`
#           无字典 →「那个，阿奈去哪了？」（译错）
#           有字典 →「凪咲去哪了？」（正确）
#
#   老格式（逗号分隔、无译文）仍然可用，按「专有名词必须原样保留」处理：
#       凪咲,三野轮凪咲
#
# 两个读者（v1.30.4 起）：
#   1) 第 2 步识别（Haas-ja）—— 作为 ASR 热词，让罕见人名更容易听对。
#      代价：解码从 greedy 换 beam search，120 秒音频约 +2~3 秒（+12~19%）。
#      不想要可设 ASMR_ASR_HOTWORDS=off。
#   2) 第 3 步翻译 —— 作为术语表按句注入（见上）。
#      不想用可设 ASMR_TRANSLATE_CTX=0（连同上文参考一起关）。
#
# 文件名规则：
#   hotwords.txt              对所有作品生效（放通用词）
#   hotwords_<音频名>.txt     只对某个音频生效
#                             （<音频名> = 0pre 里的文件名去掉扩展名，
#                              例如 official01.wav → hotwords_official01.txt）
#
# 建议只放【人名、地名、作品专有词】—— 通用词已经内置。
#
# 实测（R4222 第1轨，老格式，翻译侧）：
#   放 凪咲,三野轮凪咲,神社,巫女,迷途者,污秽 之后
#   · 错译「渚沙」6 次 → 0 次
#   · 「神社」0 次 → 2 次
#   · 字幕条数 63 → 52（更贴近官方的 56 条）
#
# 示例（TAB 用制表符分隔，不要用空格）：
# 凪咲	凪咲	name, girl, 女主角
# 三野轮凪咲	三野轮凪咲	full name
# 神社	神社	place
