#   所以这里用 == 而不是 >=。升级前必须先跑验证脚本：
#       python _haas_test/bench_haas.py <样本.wav>
#   确认识别结果没劣化再改这个版本号。

#     env\python.exe -m pip install -r app\requirements-asr.txt
