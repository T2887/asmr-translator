ASMR 日语语音 → 中文翻译  v1.18.0
==================================================

【安装】需要装两个包，装到【同一个目录】才能用
--------------------------------------------------

  1_主程序_安装包.exe          约 3 MB    ← ★ 先装这个
  2_运行环境_安装包.exe        约 5 MB    ← 再装这个
  2_运行环境_安装包-1.bin      约 2 GB    ┐
  2_运行环境_安装包-2.bin      约 2 GB    │ 这三个【不用点】，但必须和
  2_运行环境_安装包-3.bin      约 0.5 GB  ┘ 上面的 exe 放在同一个文件夹里

  安装顺序：先装 1，再装 2。

  ★ 两个包必须装到【同一个目录】。用默认路径最省事 ——
    两个包共用同一个产品标识，所以装第二个时会【自动沿用】
    第一个选的目录，不会装错地方。

  ★ 装完第一个包时，如果问「是否立即启动」，请先选【不启动】。
    因为运行环境还没装，这时启动会显示设备检测失败。
    等两个都装完再启动。

  （反过来先装 2 再装 1 也能用，编号只是建议顺序。
    但按 1 → 2 装，目录不容易搞错。）

  卸载：两个包共用一个卸载入口（控制面板里只会看到一个
        「ASMR 自动翻译工具」），卸载时两个包的文件会一起删掉，
        不需要卸两次。

  为什么拆成两个包：
    · 运行环境（PyTorch + 模型 + ffmpeg）有 8 GB 多，
      没法塞进单个安装文件（Inno Setup 单文件上限 4.2 GB）
    · 程序本体改动频繁 —— 以后升级只需要重下 3 MB 的主程序包

【启动】
--------------------------------------------------
  双击【ASMR自动翻译工具.exe】即可，或者用桌面/开始菜单的快捷方式。

  不需要任何启动脚本 —— 程序是无黑框的 Windows 程序，
  并且会自己找到所在目录作为工作目录，放哪儿都能跑。

【用法】
--------------------------------------------------
  1. 点「添加文件」或「添加文件夹」，也可以直接把视频拖进窗口
  2. 默认勾选「字幕直接放到视频旁边」—— 这样播放器会自动加载
     取消勾选的话，字幕会放到下面显示的「输出目录」里，
     那里的路径可以点「更改…」自己选
  3. 点「开始处理」，等四个步骤跑完（之后会自动整理字幕时间轴）

  处理过程中：
    · 「进度」卡片会显示当前阶段、已用时间、预估剩余
    · 「实时翻译预览」会随着识别逐条显示字幕
    · 「运行日志」显示脚本输出。日志区只显示最近几行，
      要完整的记录点上面的【导出完整日志】按钮

  字幕文件名是  <视频名>.chs.srt
    .chs 是语言代码，播放器靠它识别中文字幕。
    如果叫 xxx_中文字幕.srt，PotPlayer 这类播放器【不会】自动加载。

【过程文件会自动清理】
--------------------------------------------------
  字幕一生成完，中间文件（0pre、1audio、2vad）就会彻底删除，
  不进回收站。中途点「停止」也会立刻清掉。
  只有最终字幕会保留。

  （3asr 目录里的 srt 会保留，那是字幕的原始产物，方便你比对。）

【要求】
--------------------------------------------------
  · NVIDIA 显卡（需要 CUDA）。显存建议 8 GB 以上
  · Windows 10 / 11 64 位
  · 磁盘空间：安装占约 8.6 GB，处理时还要临时空间
    （视频转 flac 可能几 GB），建议留 20 GB
  · 【不需要联网】—— Python 环境、模型、ffmpeg 全部内置

  速度参考：1 小时视频约 7 分钟，2 小时视频约 14 分钟
  （RTX 5070 实测，人声分离占一半时间）

  ★ 如果是笔记本（有核显 + 独立显卡）：
    程序有可能被系统分配到核显上，那样会用不了 CUDA。
    判断方法：看界面「设备状态」那栏，
      显示「GPU：NVIDIA ... （已启用 CUDA）」→ 正常
      显示「CPU 模式（无 NVIDIA 显卡）」→ 需要手动指定：
        打开 NVIDIA 控制面板 → 管理 3D 设置 → 程序设置 →
        添加 ASMR自动翻译工具.exe → 首选图形处理器选
        「高性能 NVIDIA 处理器」，然后重启程序。

【目录说明】
--------------------------------------------------
  ASMR自动翻译工具.exe   主程序
  app\                   处理脚本与配置（不要删除；含 词表.txt / events.py）
  env\                   内置的 Python 运行环境（隐藏）
  env\ffmpeg\ffmpeg.exe  内置的 ffmpeg（隐藏）—— 用来从视频提取音频
  model\                 模型文件（隐藏）
  0pre / 1audio / 2vad / 3asr   程序的工作目录（隐藏，会自动清理）
  hotwords.txt           按作品补充热词（可填人名，详见文件内说明）
  _运行日志.txt          每次运行的完整日志（自动生成，可随时删除）

【常见问题】
--------------------------------------------------
  问：点了开始没反应？
  答：先看「运行日志」有没有报错。如果列表是空的，
      程序会弹一个提示框让你先添加文件。

  问：一直显示「正在加载模型」？
  答：模型首次加载确实慢（要初始化 CUDA）。界面上的
      「已用时间」在跳就说明程序在干活，不是卡死。

  问：预估剩余时间准不准？
  答：前一两分钟显示「计算中…」是正常的（模型在初始化）。
      之后会给出估算，实测误差在合理范围内。

  问：能不能用 AMD / Intel 显卡？
  答：不能。本程序依赖 CUDA。PyTorch、ONNX Runtime、CTranslate2
      在 Windows 上都没有可用的 A 卡后端，所以只能用 CPU
      （速度约为 GPU 的 1/50）。
